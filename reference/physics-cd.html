Secondary Current Distribution (cd)

Current distribution in an electrolyte with electrode kinetics (primary: equilibrium electrodes; secondary: Butler-Volmer, Tafel, linearized or user-defined kinetics).

Category

Electrochemistry › Primary and Secondary Current Distribution

Name (tag)

cd

Space dimensions

3D, 2D, 2D axisymmetric

Studies

Stationary, Time Dependent

Dependent variables

phil Electrolyte potential (V)

Default features

Electrolyte, Initial Values, Insulation

\(\nabla\cdot\mathbf{i}_l = Q_l,\quad \mathbf{i}_l=-\sigma_l\nabla\phi_l,\quad -\mathbf{n}\cdot\mathbf{i}_l = i_{loc}(\phi_{s,ext}-E_{eq}-\phi_l)\)

Material properties used: Electrical conductivity (σ).
