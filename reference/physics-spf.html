Laminar Flow (spf)

Incompressible laminar Navier-Stokes flow (P1-P1 stabilized). Elmer FlowSolve.

Category

Fluid Flow › Single-Phase Flow

Name (tag)

spf

Space dimensions

3D, 2D, 2D axisymmetric

Studies

Stationary, Time Dependent

Dependent variables

u Velocity field, x component (m/s), v Velocity field, y component (m/s), w Velocity field, z component (m/s), p Pressure (Pa)

Default features

Fluid Properties, Initial Values, Wall
