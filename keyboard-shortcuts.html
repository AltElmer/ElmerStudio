Keyboard and mouse

Documentation

The front page of this documentation. File  About Elmer Studio shows the version and the Elmer in use.

Standard keys work in the Model Builder tree as in any tree view: the arrow keys move through it, and Right and Left expand and collapse branches.

Mouse in the Graphics window

Action 3D models

Left-drag

Rotate

Right-drag

Pan

Wheel

Zoom

Left-click

Select or deselect the entity under the cursor (when a selection list is active)

Hover

Highlight the entity under the cursor: red if a click adds it, green if it’s already selected and a click removes it. The status bar names it, for example Boundary 6.

Up / Down (or + / -)

Step through the entities under the cursor, front to back, to reach a hidden face. The status bar says which one is highlighted (2 of 3 under the cursor); click to select it.

In 2D and 2D axisymmetric models there is nothing to rotate, so left-drag pans as well.

A click selects only when the mouse didn’t move. A small drag rotates or pans without changing the selection.

Selecting entities

  1. Select a feature with a selection, for example Temperature 1, in the Model Builder. Its selection list becomes active: the green button next to the list is on, and the Graphics window shows the selection level (domains, boundaries, edges or points).

  2. Hover to find the entity, then click it to add it (blue). Click a blue entity to remove it.

  3. Use Select All or Clear Selection in the Graphics toolbar (Ctrl+A, Ctrl+D), or the buttons beside the list. Paste Selection takes typed numbers such as 1, 3-5 and 8.

  4. To reach a face behind others, hover over it and press Down until it’s highlighted, then click. Or turn on Transparency. Show Labels shows the entity numbers.

For selections that should survive geometry changes, use a geometry Box Selection. See Selections.

Context menus

Right-click any node in the Model Builder for what you can add to it and do with it. The same commands as the ribbon, filtered to that node. On a physics interface the menu is split into Domains and Boundaries. On Geometry it’s split into Primitives, Booleans and Partitions, Transforms and Other.
