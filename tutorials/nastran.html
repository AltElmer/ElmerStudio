NASTRAN-95: One Model, Two Solvers

Elmer Studio can hand a study to NASTRAN-95, the public-domain release of NASA’s structural analysis program, instead of ElmerSolver. You build the model once; a single setting on the study decides which program solves it. In this tutorial you solve four small models with NASTRAN-95, read its input deck, compare the results with closed-form solutions, and solve the same models with Elmer to see both programs agree.

What you will learn

  • Switch a study between the Elmer and NASTRAN-95 backends.

  • Read the NASTRAN-95 Bulk Data deck that Elmer Studio writes.

  • Solve linear statics (SOL 1), normal modes (SOL 3) and steady heat conduction (HEAT 1) in 2D and 3D.

  • Judge the accuracy of NASTRAN-95’s linear elements, and refine the mesh where they need it.

The static and heat models solve in a second or two, the eigenfrequencies in about a minute. The same models run in the automated test suite (tests/test_nastran.py) and as scripts in examples/nastran.

Before you start: install NASTRAN-95

  1. Download a NASTRAN-95 release for your system from Foadsf/NASTRAN-95/releases (Windows, Linux and macOS) and unpack it. On Windows you can also use a Linux build inside WSL.

  2. Open File  Preferences…​ and set NASTRAN-95 installation folder to the unpacked folder, the one that contains nastran (or dist/bin/nastran) and the rf folder. The line under the field confirms the installation it found. For a build inside WSL, set the environment variable NASTRAN_WSL_HOME to its Linux path instead, for example /home/<user>/NASTRAN-95, and restart Elmer Studio.

See NASTRAN-95 backend for the full lookup order.

Part 1: Axial bar in tension

A steel bar 1 m long and 50 mm high is fixed at its left end and pulled at the right end by a stress of 20 MPa. In 2D, Elmer Studio models a slice of unit depth; with plane stress the bar stretches by σL/E = 20 MPa · 1 m / 200 GPa = 0.1 mm, and the stress is 20 MPa everywhere.

Build the model

  1. Click File  New and choose Model Wizard. Choose 2D, add Structural Mechanics › Solid Mechanics (solid), and choose the Stationary study.

  2. Click Geometry 1, then Geometry  Rectangle. Set Width to 1[m] and Height to 5[cm], and press F8 (Build All Objects).

  3. Click Home  Add Material and add Built-in › Structural steel. It covers the whole bar: E = 200 GPa, ν = 0.3.

  4. Click Solid Mechanics (solid) and set 2D approximation to Plane stress.

  5. Click Physics  Boundaries  Fixed Constraint and click the left edge.

  6. Click Solid Mechanics (solid) again, click Physics  Boundaries  Boundary Load and click the right edge. Keep Load type Force per unit area and set F_A x to 20[MPa].

  7. On the Mesh ribbon, click Mesh  Free Triangular. Click Size 1, set Element size to Custom, Maximum element size to 5[cm] and Minimum element size to 2[cm].

Choose NASTRAN-95

  1. Click Study 1. In the section Study Settings, set Solver backend to NASTRAN-95.

    Figure 1. Study 1 solved by NASTRAN-95

The ribbon button Show Elmer Input File becomes Show NASTRAN Input Deck. If NASTRAN-95 cannot solve the model, Compute is unavailable and its tooltip gives the reason.

Read the input deck

  1. Click Study  Show NASTRAN Input Deck.

    Figure 2. The NASTRAN-95 input deck

The deck has three parts:

  • the Executive Control (APP DISP, SOL 1): linear statics;

  • the Case Control: which constraint and load sets to use (SPC = 1, LOAD = 1) and which results to print;

  • the Bulk Data: a GRID card for every mesh node, the material (MAT1), the 2D property (PSHELL, unit thickness), the elements, the constraints (SPC1) and the loads (FORCE).

Every 6-node triangle of the mesh is written as four 3-node CTRIA3 elements that share its nodes, because NASTRAN-95 has no 6-node triangle that reproduces a uniform stress exactly. The 20 MPa on the right edge appears as nodal forces: the stress times the edge area of each element side, shared by its nodes. Save As…​ writes the deck to a .bdf file that you can run with NASTRAN-95 by hand.

Solve and look at the stress

  1. Click Home  Compute.

The Log window shows NASTRAN-95’s output, ending with END OF JOB. Results gets the Stress (solid) plot group: the von Mises stress on the deformed bar.

Figure 3. Von Mises stress from NASTRAN-95: 20 MPa throughout

Check the results

Click the plot at the right end of the bar to read the values there (see Results), or evaluate u and solid.mises with a Point Evaluation.

Part 2: Eigenfrequencies of a cantilever

The same bar, clamped at the left end and free at the right, vibrates in bending. Euler–Bernoulli beam theory gives its first frequency as

f1 = 1.8751² / (2π L²) · √(E h² / (12 ρ)) = 40.77 Hz

for L = 1 m, h = 50 mm and ρ = 7850 kg/m³, and the second as 6.267 times the first.

  1. Start a new 2D model with Solid Mechanics and the Eigenfrequency study, and repeat the geometry, material, 2D approximation Plane stress and Fixed Constraint of Part 1. There is no load.

  2. On the Mesh ribbon, click Mesh  Free Triangular. In Size 1, set Maximum element size to 12.5[mm] and Minimum element size to 5[mm]: four elements through the depth of the beam.

  3. Click Study 1, set Solver backend to NASTRAN-95, and click Home  Compute.

NASTRAN-95 solves rigid format 3 (normal modes) with the FEER method and returns the six lowest modes, as many as Desired number of eigenfrequencies asks for. The Mode Shape (solid) plot group shows the first mode; choose the others under Eigenfrequency in its settings.

Both programs give the same mode shapes. NASTRAN-95’s frequencies are 1 % higher than Elmer’s because its 3-node triangles are stiffer in bending than Elmer’s 6-node triangles. With the coarser 5 cm mesh of Part 1, one element through the depth, the difference would be about 10 %: for bending, give NASTRAN-95 at least four linear elements through the thickness. Both programs fall below beam theory for f2, which ignores shear and rotary inertia.

Part 3: Steady heat conduction

A steel plate 1 m by 20 cm is held at 350 K on its left edge and 300 K on its right edge; the other edges are insulated. The temperature falls linearly from left to right.

  1. Start a new 2D model with Heat Transfer › Heat Transfer in Solids (ht) and the Stationary study.

  2. Draw a rectangle of Width 1[m] and Height 20[cm], and add Structural steel.

  3. Click Physics  Boundaries  Temperature, click the left edge and set Temperature to 350[K]. Add a second Temperature on the right edge with 300[K].

  4. Add a Free Triangular mesh with a Size of 10[cm] maximum and 5[cm] minimum.

  5. Set the study’s Solver backend to NASTRAN-95 and click Home  Compute.

NASTRAN-95 runs its heat transfer approach (APP HEAT) with the fixed temperatures as SPC cards.

Figure 5. Temperature from NASTRAN-95

Check the results

The temperature at every node is within 0.0002 K of 350 K − 50 K · x / 1 m. Heat flux and convection boundaries are not mapped to NASTRAN-95: with one of them in the model, Compute is unavailable and says so.

Part 4: Axial bar in 3D

  1. Start a new 3D model with Solid Mechanics and the Stationary study.

  2. Click Geometry 1, then Geometry  Block. Set Width 1[m], Depth 1[cm] and Height 5[cm], build it, and add Structural steel.

  3. Add a Fixed Constraint on the face at x = 0 and a Boundary Load on the face at x = 1 m with Load type Total force and F_tot x 10[kN].

  4. Add a Free Tetrahedral mesh with a Size of 10[cm] maximum and 5[cm] minimum.

  5. Set the study’s Solver backend to NASTRAN-95 and click Home  Compute.

Each 10-node tetrahedron of the mesh becomes eight 4-node CTETRA elements. The cross-section is 5 cm², so the stress is 20 MPa and the elongation PL/EA = 0.1 mm.

In tension the linear tetrahedra do well: on this coarse mesh, with one element through the 1 cm depth, NASTRAN-95 is within 1.5 %. In bending they are much stiffer than Elmer’s quadratic ones: a 3D cantilever with one element through its depth deflects 40 % less with NASTRAN-95. The accuracy table lists the measured differences.

Run the models as scripts

The four models are also scripts in examples/nastran. Each builds the model through the Python API, solves it with NASTRAN-95, prints the result next to the closed-form value, saves the .esm project and a picture:

python examples/nastran/axial_bar_2d.py
python examples/nastran/cantilever_modes_2d.py
python examples/nastran/heat_2d.py
python examples/nastran/axial_bar_3d.py

See Scripting a model in Python for the API.
