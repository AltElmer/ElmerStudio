= Tutorials
:description: Step-by-step models, from a first heat transfer model to electrochemistry, each checked against a known answer.
:page-pagination!:

Each tutorial builds a complete model in the GUI, click by click, and ends with *Check the results*: the numbers you should see, compared with a closed-form solution, a benchmark or theory. The same models run in the automated test suite, so the numbers hold for the version you're using.
