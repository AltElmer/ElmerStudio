= Coming from COMSOL
:description: How COMSOL Multiphysics concepts map to Elmer Studio, and the differences to know about.

Elmer Studio follows COMSOL's workflow, layout and names on purpose. If you know COMSOL, you already know most of it. This page lists what corresponds to what, and the few places where it differs.

NOTE: Elmer Studio is independent of COMSOL AB. It does not read or write `.mph` files.

== Concept map

[cols="2,2,2",options="header"]
|===

== Variable names

Result variables use COMSOL's scoped names where possible: `+T+`, `+ht.tfluxMag+`, `+solid.mises+`, `+solid.disp+`, `+es.normE+`, `+ec.normJ+`, `+mf.normB+`, `+spf.U+`, `+acpr.p_t+`, `+acpr.Lp+`, `+cd.phil+`, `+cd.iloc+`, `+cd.es1.Itot+`. The full list is in xref:reference:result-variables.adoc[Result variables].

== Differences to know

[cols="1,3",options="header"]
|===
|Topic |In Elmer Studio
|Materials |Library values are constants at 20 °C. Use expressions or Interpolation functions for temperature dependence.
|Coupling operators |Evaluated on results. They can't appear inside the equations.
|Identity pairs |Continuity only (no contact, thin layers or other pair conditions); for Heat Transfer, Electrostatics, Electric Currents and the Coefficient Form PDE.
|Several components |Each solves on its own mesh; one component can use another's coupling operators (one way), not its fields.
|Boundary-layer meshes |Not exposed.
|Adaptive mesh refinement |Not available.
|Magnetic fields |2D and 2D axisymmetric only; no 3D A–V formulation.
|Turbulence, contact, structural transient and frequency response |Not available yet.
|Acoustic BEM and PMLs |Open domains use Spherical Wave Radiation, and the field beyond the mesh comes from the Exterior Field Calculation.
|Probes and animations |Not available yet.
|Application Builder, LiveLink |Not available.
|Integrals over quadratic elements |Use linearized cells (about 0.1 % on smooth fields), except boundary fluxes from reaction loads (electrode currents, heat flows), which are exact.
|===

The complete list is on xref:known-limitations.adoc[Known limitations].

== Habits that carry over

* Later features override earlier ones on shared boundaries.
* kbd:[F7] / kbd:[F8] build, kbd:[Ctrl+=] computes, kbd:[F2] renames, kbd:[F3]/kbd:[F4] disable and enable, kbd:[F1] opens the help of the selected node.
* kbd:[Ctrl+Tab] and kbd:[Ctrl+Alt+Left]/kbd:[Right]/kbd:[Up]/kbd:[Down] move between windows and Settings sections; kbd:[Ctrl+Space] completes expressions; kbd:[Ctrl+A]/kbd:[Ctrl+D] select all and clear in the Graphics window.
* kbd:[Esc] in a Settings field puts back the applied value. COMSOL's manual doesn't describe this key, so this is Elmer Studio's own choice.
* Entity numbers follow position, so numbers in COMSOL instructions usually match.
* Parameters with units, sweeps, couplings and Global Evaluations work as you expect.
