= The desktop
:description: The windows of Elmer Studio and what each one is for.

The Elmer Studio desktop has the same layout as COMSOL's. On the left, the *Model Builder* holds the model as a tree, and the *Settings* window shows the selected node. The ribbon is on top, the *Graphics* window in the middle, and the information panes underneath.

Every window is a dock: drag its title to move it, double-click to float it, or close it. menu:Home[Reset Desktop] restores the default layout.

The *File* menu holds New, Open, Recent, Save, Save As, Application Libraries, Export Elmer Case, Preferences, Documentation, About and Exit. menu:File[Preferences...] sets the Elmer installation (see xref:installation.adoc#install-elmer[Installation]).

== Model Builder

The tree has the same structure as a COMSOL model:

* *Global Definitions*: parameters and functions shared by everything.
* *Component 1*: one geometry with its *Definitions* (variables, couplings), *Geometry*, *Materials*, physics interfaces, *Multiphysics*, and *Mesh*.
* *Study 1*, *Study 2*, …: study steps, parametric sweeps and solver configurations.
* *Results*: datasets, derived values, tables, plot groups and export.

The toolbar above the tree has *Go Back* and *Go Forward* (through the nodes you selected), *Move Up* and *Move Down* (kbd:[Ctrl+Up], kbd:[Ctrl+Down]), *Expand All* and *Collapse All*.

Right-click a node to see what you can add to it. Every node also has *Rename* (kbd:[F2]), *Duplicate* (kbd:[Ctrl+Shift+D]), *Delete* (kbd:[Delete]), *Disable* (kbd:[F3]) and *Enable* (kbd:[F4]), and *Move Up/Down*. Disabled nodes are greyed out and ignored when building and solving, as in COMSOL. Default features (such as *Thermal Insulation 1*) can't be deleted or disabled. Add a feature after them to override them on some boundaries.

Double-click a node to build, compute, plot or evaluate it, the same as kbd:[F8].

== Settings window

The Settings window shows the selected node's settings in sections that you can expand and collapse. Typical sections:

* *Label*: the node's label (editable) and its name, used in expressions (`+aveop1+`, `+cd.es1+`, …).
* *Domain/Boundary Selection*: which entities the feature applies to. See xref:user-guide:selections.adoc[Selections].
* *Equation*: the equation the feature contributes, as COMSOL shows it.
* the feature's own settings, with the symbol on the left and the SI unit on the right of each field.

Fields accept expressions with parameters, functions, units and, where it makes sense, the dependent variables (`+T+`, `+phil+`, …). A field with an invalid expression turns pink. Results nodes have a *Plot* or *Evaluate* button at the top.

== Messages, Progress, Log and Table

[cols="1,4",options="header"]
|===
|Pane |Shows
|*Messages* |One line per action: geometry and mesh statistics, solver runs, solution times, warnings and errors. When Elmer stops with an error, its own `ERROR::` line is quoted here.
|*Progress* |The running job: study step, sweep or time step, and a progress bar. menu:Study[Stop] cancels it.
|*Log* |ElmerSolver's own output, live.
|*Table* |The results of evaluations (integrals, maxima, point values, global values) and mesh statistics. Copy them, or export them as CSV.
|===

While a study runs, a *Convergence Plot* tab next to *Graphics* shows the nonlinear and coupling convergence of each Elmer solver.

== Windows that open on demand

* *Add Material* (menu:Home[Add Material]): the material library on the right, with a property preview.
* *Model Wizard* and *New* (menu:File[New]).
* *Elmer input file* (menu:Study[Show Elmer Input File]): the generated `.sif`, read-only.
* *Preferences* (menu:File[Preferences...]): the Elmer installation.
