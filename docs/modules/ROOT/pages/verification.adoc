= Verification
:description: The analytical solutions and benchmarks Elmer Studio is checked against on every change.

Every change to Elmer Studio runs a test suite that builds models through the same code the GUI uses, solves them with real Elmer, and compares the results with closed-form solutions or published benchmarks. The tests run on Linux (with the official Elmer PPA), Windows and macOS on every push (the solver tests need Elmer, so they run on Linux).

== Tutorials

Each tutorial's *Check the results* section is a test as well: the busbar (energy balance, bolt temperatures, sweep trend), the wrench (deflection convergence against beam theory), the postprocessing and acoustics walkthroughs, and the electrochemistry tutorials.

== Run the tests yourself

From a source checkout, with Elmer installed:

[source,bash]
----
pip install pytest
pytest tests -v
python tests/test_gui_smoke.py      # drives the real main window through nearly every command
----

Tests that need Elmer are skipped when it isn't found.
