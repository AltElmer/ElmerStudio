They are generated from the same model schema the GUI is built from, by `tools/gen_docs_reference.py`, so they match the version of Elmer Studio they were built with. The build regenerates them and fails if the committed pages are out of date.

== Reading the tables

* *Unit* is the SI unit of the field. You can always write another unit in brackets, `+5[mm]+`. "length unit" means the geometry's length unit.
* *Default* is the value a new node starts with.
* *Choices / type* lists the options of a list, or the kind of input (expression, check box, table, …).
* Some settings appear only for certain choices of others, for example the Butler–Volmer parameters only for Butler–Volmer kinetics.
